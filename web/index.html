      내보내기

      로그인한 아이디가 저장한 라벨, 저장 기록, 메모가 들어갑니다. 팀원과 비교하려면 각자 받은 엑셀을 아래에서 합치세요.

      라벨 결과 · 작업 이력 · 작업자 요약 · 파일 현황 · 정보 파일별 비프 구간(초) + 상태 + 메모 100 ms 칸별 overlap_ms, label 저장 기록 비프 구간을 지정한 모든 파일의 구간을 잘라 WAV로 묶음 (폴더를 열어 둔 상태에서) 
      
  
      
  
      여러 사람의 엑셀 합치기
      
  
      팀원들이 각자 내보낸 엑셀(.xlsx)을 모두 선택하면 한 엑셀로 합쳐집니다. 파일 현황 시트에 작업자 간 일치(±20 ms)가 나옵니다. 같은 파일·같은 아이디는 가장 최근 저장본을 씁니다. 파일은 이 브라우저 안에서만 처리됩니다.
      
  
  
      
  
      
  
      
  
      
      


  
      백업 · 초기화 · 계정
      
  
      기록은 온라인 저장소에 아이디별로 있습니다. 혹시 모르니 가끔 백업 파일도 받아 두세요.
      
  
      
    
      
  
      
    온라인 저장으로 바뀌기 전에 이 브라우저에서 작업한 기록을 내 아이디로 옮깁니다.
      
  
      
  
      처음 상태로 초기화
      
  
      폴더에서 처음 가져왔을 때처럼 비프 구간 · 메모 · 상태 · 저장 기록을 모두 지웁니다. 원본 WAV 파일은 바뀌지 않습니다. 되돌릴 수 없으니 필요하면 먼저 백업하세요.

      사용법 · 단축키
      
  
      
    
      드래그비프 구간 지정 (길이 제한 없음, 10 ms 단위, 파일당 1구간)
      
    
      클릭클릭 지점 중심 ±50 ms, 100 ms 구간 선택
      
    
      가장자리 드래그시작/끝 조정 (10 ms 단위)

      Esc정지
      
    
      [ ]  ; '구간 시작 / 끝 ∓10 ms (Shift: 100 ms)
      
    
      휠, Shift+휠확대·축소, 좌우 이동
      
    
      = - F B T확대 / 축소 / 전체 보기 / 스펙트로그램 크게 / 테마

      상태(미작업 · 작업 중 · 검수 완료)는 파일 이름 옆 버튼으로 언제든 바꾸고 저장하면 됩니다. 브라우저는 보안상 폴더 위치를 기억할 수 없어서, 다시 로그인하면 같은 WAV 폴더를 한 번 다시 선택해야 합니다. 크롬 또는 엣지를 권장합니다.
