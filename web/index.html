      로그인한 아이디의 라벨, 작업 이력(언제 · 무엇을 · 어떻게), 메모가 들어갑니다. 팀원과 비교하려면 각자 받은 엑셀을 아래에서 합치세요.

      라벨 결과 · 작업 이력 · 작업자 요약 · 파일 현황 · 정보 파일별 비프 구간(초) + 메모 100 ms 칸별 overlap_ms, label 작업 이력

      여러 사람의 엑셀 합치기

      팀원들이 각자 내보낸 엑셀(.xlsx)을 모두 선택하면 한 엑셀로 합쳐집니다. 파일 현황 시트에 작업자 간 일치(±20 ms)가 나옵니다. 같은 파일·같은 아이디는 가장 최근 수정본을 씁니다. 파일은 이 브라우저 안에서만 처리됩니다.

      
  
      
  
      
      


  
      백업 · 복원
      
  
      기록은 이 브라우저에만 있어서, 브라우저 기록(사이트 데이터) 삭제, 시크릿 창, 다른 PC·브라우저에서는 보이지 않습니다. 가끔 백업 파일을 받아 두세요. 다른 PC에서 이어서 하려면 거기서 복원하면 됩니다.
      
  
      
    
      
  
      
  
      
      


  
      사용법 · 단축키
      
  
      
    
      드래그비프 구간 지정 (0~100 ms, 1 ms 단위, 파일당 1구간)
      
    
      클릭클릭 지점 중심 ±50 ms, 100 ms 구간 선택
      
    
      가장자리 드래그시작/끝 조정 (최대 100 ms 유지)
      
    
      구간 안 드래그구간 이동
      
    
      시간축 클릭재생 커서 이동
      
    
      Space / Enter전체 듣기(커서부터) / 구간만 듣기
      
    
      Esc정지
      
    
      [ ]  ; '구간 시작 / 끝 ∓1 ms (Shift: 10 ms)
      
    
      A / Delete자동 제안 적용 / 비프 없음
      
    
      휠, Shift+휠확대·축소, 좌우 이동
      
    
      = - F B T확대 / 축소 / 전체 보기 / 스펙트로그램 크게 / 테마
      
    
      R검수 완료 + 다음 파일
      
    
      N P (↓ ↑)다음 / 이전 파일
      
    
      Ctrl+S, Ctrl+Z저장(자동 저장도 됨), 실행 취소
      
  
      
  
      브라우저는 보안상 폴더 위치를 기억할 수 없어서, 다시 로그인하면 같은 WAV 폴더를 한 번 다시 선택해야 합니다. 라벨·메모·이력은 그대로 이어집니다. 크롬 또는 엣지를 권장합니다.
