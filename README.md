# Beep Labeler

차량 비프음 데이터셋에서 **비프가 나는 구간을 표시하는** 라벨링 도구입니다. 팀원이 각자 자기 PC에서
작업하고, 내보낸 엑셀을 합쳐서 결과를 비교합니다.

- **아이디만으로 로그인**(비밀번호 없음)합니다. 그 아이디로 한 작업(언제 · 어떤 파일의 몇 초~몇 초를 ·
  어떻게 바꿨는지)은 **그 아이디에만** 기록되고, 화면에는 로그인한 아이디 자신의 기록만 보입니다.
- 아이디마다 **자기 WAV 폴더**(내 PC 폴더 또는 NAS)를 지정합니다. 로그아웃했다가 같은 아이디로 다시
  로그인하면 그 폴더와 이전 작업(라벨, 메모, 작업 이력, 마지막 파일, 테마)이 그대로 돌아옵니다.
- 샘플(파일)마다 **비프 구간은 1개**, 길이는 **0~100 ms**입니다(1 ms 단위). 클릭하면 그 지점 ±50 ms의
  100 ms 구간이 선택됩니다. 오디오는 자르지 않고 표시만 합니다.
- **엑셀(.xlsx)**로 내보내면 라벨 결과, 작업 이력, 작업자 요약, 파일 현황, 정보 시트가 만들어집니다.
  CSV(초 범위 + 메모)도 함께 제공합니다.
- 전체 듣기 / 구간만 듣기, 검은·흰 배경 테마, 스펙트로그램 크게 보기, 자동 제안 구간을 지원합니다.
- 설치형 프로그램입니다. Claude 없이 누구나 git으로 받아 실행할 수 있습니다.

---

## 1. 설치 · 실행

### Windows (가장 쉬움)
1. Python 3.9 이상을 설치합니다. 설치 화면에서 **Add python.exe to PATH**를 체크하세요.
2. 저장소를 받습니다.
   ```bash
   git clone https://github.com/<계정>/beep-labeler.git
   ```
3. `beep-labeler` 폴더에서 **`run_windows.bat`을 더블클릭**합니다. 처음 한 번만 자동 설치되고,
   브라우저가 열립니다.

### macOS / Linux
```bash
git clone https://github.com/<계정>/beep-labeler.git
cd beep-labeler
./run.sh
```

### pip로 직접
```bash
pip install git+https://github.com/<계정>/beep-labeler.git
beeplabel serve
```

### 업데이트
```bash
git pull
```
그 다음 `run_windows.bat`을 다시 실행합니다. 코드를 수정한 경우에는 `.venv` 폴더를 지우고 실행하면
새로 설치됩니다.

## 2. 처음 사용할 때

1. 브라우저 화면에서 **자기 아이디**를 입력합니다(회원가입). 처음 쓰는 아이디면 "새 아이디로 시작할까요?"라고
   한 번 확인합니다(오타로 아이디가 둘로 나뉘는 것을 막기 위해서입니다). 다른 사람의 아이디 목록은 보이지 않습니다.
2. **설정 → WAV 데이터 폴더 경로**에 WAV 파일이 든 폴더를 입력합니다. 하위 폴더까지 찾습니다.
   - 내 PC 폴더: `D:\beep_dataset`
   - NAS: `\\NAS이름\공유폴더\beep` 또는 드라이브로 연결한 `Z:\beep`
   - 경로는 **이 아이디에만** 저장되고, 다음에 로그인하면 자동으로 열립니다. NAS가 끊겨 있으면
     "폴더에 접근할 수 없음"이 표시되니 연결 후 다시 여세요.
   - 미리 지정할 수도 있습니다: `beeplabel set-dataset D:\beep_dataset --user hong`
     (`--user` 없이 지정하면 폴더를 정하지 않은 아이디에 쓰이는 기본 폴더가 됩니다)

> ⚠ 비밀번호가 없으므로 같은 PC를 쓰는 사람은 다른 아이디로도 로그인할 수 있습니다. 엑셀의 "작업자"는
> 본인 확인을 거친 값이 아닙니다.

## 3. 여러 명이 함께 쓰는 방법 (각자 PC → 엑셀 합치기)

1. 작업자마다(예: 5명) **자기 PC**에 git clone 후 `run_windows.bat`으로 실행하고, 자기 아이디로 라벨링합니다.
   기본 설정(127.0.0.1)은 그 PC에서만 접속되므로 다른 사람이 들어올 수 없습니다.
2. 각자 **엑셀/CSV 내보내기 → 📊 엑셀**로 `.xlsx`를 받아 팀에 공유합니다. 파일 이름에 아이디가 들어가고
   (`beep_labels_hong_20261001_1030.xlsx`), **로그인한 아이디 자신의 작업만** 들어갑니다.
3. 한 사람이 **엑셀/CSV 내보내기 → 여러 PC의 엑셀 합치기**에서 받은 파일들을 한꺼번에 선택하면
   `beep_labels_merged_YYYYMMDD_HHMM.xlsx`가 만들어집니다.
   CLI로도 합칠 수 있습니다: `beeplabel merge hong.xlsx kim.xlsx lee.xlsx -o merged.xlsx`

합친 엑셀에 담기는 내용:
- 모든 작업자의 구간, 메모, 작업 이력이 들어가고, 각 행에 **출처 파일** 열이 붙습니다.
- **파일 현황** 시트에서 작업자 간 일치/불일치(경계 차이 ±20 ms 기준)와 경계 차이(ms)를 봅니다.
- 같은 파일·같은 아이디가 여러 엑셀에 있으면 **최종 수정 일시가 가장 늦은 것**을 씁니다.
  내용이 서로 다르면 "정보" 시트에 어떤 것을 쓰고 뺐는지 적습니다.
- 파일은 **폴더 안 경로**(예: `car_A/rec_001.wav`)로 맞춥니다. 같은 이름인데 PC마다 오디오 내용이
  다르면(SHA-256 불일치) 경고를 띄웁니다. 모두 같은 WAV 폴더 구조를 쓰세요.
- 합친 엑셀을 다시 다른 엑셀과 합칠 수도 있습니다.

(`run_windows.bat lan`으로 한 PC를 다른 PC에서 접속하게 할 수도 있지만, 비밀번호가 없으므로 권하지 않습니다.
쓴다면 믿을 수 있는 내부망에서만 쓰고 인터넷에는 공개하지 마세요.)

## 4. 라벨링 화면

| 동작 | 방법 |
|---|---|
| 비프 구간 지정 (드래그) | 파형·스펙트로그램을 **드래그**합니다. 누른 지점부터 최대 **100 ms**까지이고, 더 끌어도 100 ms에서 멈춥니다. 파일당 1구간이며 새로 지정하면 교체됩니다 |
| 비프 구간 지정 (클릭) | **클릭한 지점을 중심으로 양옆 50 ms씩**, 100 ms 구간이 선택됩니다. 파일 끝에서는 안쪽으로 밀려 100 ms를 유지합니다 |
| 경계 조정 | 구간 가장자리를 드래그합니다(최대 100 ms 유지). 또는 `[` `]`(시작) `;` `'`(끝)로 1 ms씩, Shift를 누르면 10 ms씩 |
| 구간 이동 | 구간 내부 드래그 |
| 비프 없음 | `비프 없음` 버튼 / `Delete` |
| 자동 제안 적용 | 파란 점선이 자동 탐지 결과(첫 비프 시작점부터 최대 100 ms)이고, `자동 제안 적용`(A)으로 가져옵니다 |
| **전체 듣기** | `▶ 전체 듣기` / `Space`. 커서 위치부터 끝까지 재생합니다(커서는 아래 시간축을 클릭해서 이동) |
| **구간만 듣기** | `▶ 구간만 듣기` / `Enter`. 표시한 구간만 재생합니다 |
| 스펙트로그램 크게 | `스펙트로그램 크게 보기` / `B` |
| 테마 | 오른쪽 위 ◐ / `T`. 아이디별로 기억합니다 |
| 메모 | 오른쪽 **메모** 칸. 데이터 특징을 적으면 엑셀·CSV의 `memo` 열에 들어갑니다 |
| 검수 완료 | `검수 완료 → 다음` / `R` |
| 저장 | 모든 변경은 0.8초 뒤 **자동 저장**됩니다. `Ctrl+S`로 즉시 저장할 수도 있습니다 |
| 나가기 | **`저장 후 로그아웃`** 버튼. 창을 그냥 닫아도 마지막 변경을 저장하고 경고를 띄웁니다 |

아래 100 ms 칸 줄에는 구간이 걸친 부분만 색칠됩니다. 구간이 두 칸에 걸칠 수도 있습니다.
오른쪽 **"이 파일에서 내가 한 작업"**에 로그인한 아이디가 이 파일에서 한 작업이 시간순으로 나옵니다
(다음에 다시 로그인했을 때 전에 뭘 했는지 확인하는 용도).

**작업 이력 정리**: 실수로 잘못 눌러 생긴 이력이 있으면 `이력 정리`를 눌러 지울 항목을 체크한 뒤
`선택 삭제`를 누릅니다. 삭제는 되돌릴 수 없고, 엑셀·CSV에서도 빠집니다.
- 비프 구간이나 메모 같은 라벨 자체는 바뀌지 않습니다.
- 이미 공유한 엑셀에는 지우기 전 이력이 남아 있으니, 정리한 뒤 다시 내보내세요.

## 5. 내보내기

상단 **엑셀/CSV 내보내기** 버튼을 누르거나, CLI에서 `beeplabel export -o 결과폴더`를 실행합니다.

**엑셀 (`beep_labels_YYYYMMDD_HHMM.xlsx`)**

| 시트 | 내용 |
|---|---|
| 라벨 결과 | 파일 × 작업자별 비프 구간(예: `1.234~1.310초`), 시작·끝(초), 길이(ms), 100 ms 클립 구간(구간 중심 ±50 ms), 상태, 메모, 자동탐지와의 차이(ms), 수정 횟수, 최초·최종 작업 일시 |
| 작업 이력 | 일시, 작업자, 파일, 동작(구간 지정/수정/삭제, 검수 완료/취소, 메모, 아이디 생성, 로그인/로그아웃, 폴더 변경, 내보내기), **변경 전 → 변경 후** |
| 작업자 요약 | 작업자별 작업 파일 수, 검수 완료 수, 비프 있음/없음, 평균 구간 길이, 진행률, 마지막 로그인 |
| 파일 현황 | 파일별 작업자 수, 작업자별 구간, **작업자 간 일치/불일치**(경계 차이 ±20 ms 기준), 경계 최대 차이(ms), 메모 모음 |
| 정보 | 내보낸 사람·시각, 데이터 폴더, 툴 버전, 라벨 규칙 설명 |

머리글 고정, 필터, 상태별 색상, 열 너비 자동 맞춤이 적용되어 있습니다.

**CSV** (UTF-8 BOM이라 엑셀에서 한글이 깨지지 않습니다)
- `labels.csv`: `file, user_id, status, has_beep, start_s, end_s, duration_ms, start_sample, end_sample, clip100_start_s, clip100_end_s, memo, ...`
- `frames.csv`: 100 ms 격자 칸별 `overlap_ms`(구간이 걸친 길이)와 `label`(걸쳤으면 1)
- `audit.csv`: 전체 작업 이력

메모가 `=` `+` `-` `@`로 시작해도 엑셀이 수식으로 실행하지 않도록 글자로 저장합니다.
CSV에는 이런 칸 앞에 `'`가 붙습니다.

## 6. 라벨 규칙 (논문 작성용)

- 샘플마다 비프 구간 **최대 1개**(길이 0 초과 100 ms 이하), 또는 "비프 없음"입니다.
- 경계는 샘플 단위로 저장되고, 화면과 엑셀에는 1 ms(소수 셋째 자리 초) 단위로 표시됩니다.
- **100 ms 클립 구간** = 표시한 구간의 중심 ±50 ms입니다. 나중에 100 ms 샘플을 자를 때 이 값을
  쓰면 됩니다. 파일 끝에 걸리면 안쪽으로 밀어서 100 ms를 유지합니다.
- 자동 제안 = 협대역 톤 검출기가 찾은 첫 비프의 시작점부터 최대 100 ms입니다. 파라미터는 합성
  데이터로 튜닝한 고정값입니다(합성 데이터 기준 비프 시작점 오차 약 1 ms). 정답은 사람이 검수한
  라벨입니다.
- 작업자 간 일치도: 각자 내보낸 엑셀을 **합치면** "파일 현황" 시트에 파일별 일치/불일치(경계 차이
  ≤ 20 ms)와 경계 차이(ms)가 나옵니다.
- 내 라벨과 자동 제안 비교: `beeplabel agree --users hong auto --dataset D:\beep_dataset`는 일치율,
  경계 평균 차이(ms), 100 ms 칸 단위 Cohen's κ를 출력합니다.

## 7. 데이터 저장 위치 · 백업

- 아이디, 라벨, 작업 이력은 모두 **`%USERPROFILE%\beeplabel_data\beeplabel.db`**
  (macOS/Linux는 `~/beeplabel_data/`) 파일 하나에 저장됩니다. 이 파일만 복사하면 백업이 됩니다.
- 위치를 바꾸려면 `beeplabel --data-dir D:\beep_state serve`를 쓰거나 환경변수 `BEEPLABEL_DATA`를 지정합니다.
- WAV 원본은 절대 수정하지 않습니다. 파일마다 SHA-256을 기록하므로 나중에 원본이 바뀌었는지
  확인할 수 있습니다.

## 8. 명령줄 도구

`beeplabel` 명령이 보안 정책 때문에 막히면 `python -m beeplabel ...`로 똑같이 실행할 수 있습니다
(Windows 가상환경에서는 `.venv\Scripts\python -m beeplabel users`).

```bash
beeplabel users                     # 아이디 목록
beeplabel set-dataset D:\beep_data --user hong   # 아이디별 WAV 폴더 지정
beeplabel export --user hong -o out               # 그 아이디의 작업만 내보내기
beeplabel merge a.xlsx b.xlsx -o merged.xlsx   # 여러 PC의 엑셀 합치기
beeplabel demo demo_data            # 합성 데모 WAV 생성 (체험용)
```

## 9. 개발

```bash
pip install -e ".[dev]"
pytest
```
