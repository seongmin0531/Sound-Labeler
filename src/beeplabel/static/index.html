      사용법 · 단축키

      드래그비프 구간 지정 (길이 0~100 ms, 1 ms 단위, 파일당 1구간, 새로 드래그하면 교체)
      클릭클릭 위치 중심으로 양옆 50 ms씩, 100 ms 구간 선택
      구간 가장자리 드래그시작/끝 조정 (최대 길이 100 ms 유지)
      구간 내부 드래그구간 이동
      아래 시간축 클릭재생 커서 이동
      Space전체 듣기 (커서부터) / 정지
      Enter구간만 듣기
      Esc정지
      [ ] / ; '구간 시작 / 끝을 1 ms 앞·뒤로 (Shift: 10 ms)
      A자동 제안 구간 적용
      Delete구간 삭제 = 비프 없음
      휠 / Shift+휠확대·축소 / 좌우 이동
      = - F확대 / 축소 / 전체 보기
      B스펙트로그램 크게 / 작게
