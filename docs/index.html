      확인

      내보내기

      라벨 결과 · 작업 이력 · 작업자 요약 · 파일 현황 · 정보 파일별 한 줄: 상태 · 구간 수 · 구간 목록 · 메모 100 ms 칸별 overlap_ms, label 저장 기록 저장된 모든 구간을 잘라 WAV로 묶음 (폴더를 열어 둔 상태에서) 
      
  
      
  
      여러 사람의 엑셀 합치기
      
  
      팀원들이 각자 내보낸 엑셀(.xlsx)을 모두 선택하면 한 엑셀로 합쳐집니다. 파일 현황 시트에 작업자 간 일치(±20 ms)가 나옵니다. 같은 파일·같은 아이디는 가장 최근 저장본을 씁니다. 파일은 이 브라우저 안에서만 처리됩니다.
      
  
  
      
  
      
  
      
  
      
      


  
      백업 · 초기화 · 계정
      
  
      기록은 이 브라우저에만 있어서 브라우저 기록(사이트 데이터) 삭제, 시크릿 창, 다른 PC·브라우저에서는 보이지 않습니다. 가끔 백업 파일을 받아 두고, 다른 PC에서는 그 파일을 불러오세요.
      
  
      
    
      
  
      
  
      처음 상태로 초기화
      
  
      폴더에서 처음 가져왔을 때처럼 비프 구간 · 메모 · 상태 · 저장 기록을 모두 지웁니다. 원본 WAV 파일은 바뀌지 않습니다. 되돌릴 수 없습니다.
